System Specification: T-Skill Agentic RAG Application
1. Project Overview
This project aims to build an AI-driven, Agentic Retrieval-Augmented Generation (RAG) application to evaluate an employee's "Deep and Wide" T-shaped skills. The application will interface with organizational HR data and output personalized professional development and execution plans for discussion with department leadership
.
2. Technical Architecture
MCP Client: An intelligent AI agent capable of routing queries, invoking tools, and synthesizing outputs.
MCP Server (FastMCP): A Python-based backend server that exposes specialized tools for HR data retrieval and skill gap calculations
.
Data Storage: AWS S3 buckets and/or a relational database (e.g., PostgreSQL/SQLite) to store employee profiles, skill evolution records, and learning resource mappings
.
Development & Testing: The server will be continuously tested during development using the MCP Inspector in CLI mode, which will export an mcp.json file for native Cursor integration
.
3. Core Logic & Algorithms
The system must digitize the T-Skill methodology to evaluate an employee's horizontal breadth and vertical depth.
The Skill-Value Gap Calculation
The agent must evaluate employees using the following formula
:
User Input: The user provides a self-evaluation from a "Scale of 1-5" for both "Your Skill Rating" and the "Value to Sponsor".
Formula: Skill Rating * Value to Sponsor = Total Score
Ranking: The system will rank the employee's development focus areas based on the highest total scores
.
Skill Categories
The app tracks progression across the following primary categories and their nested sub-skills
:
Data Science: (e.g., AI-Engineering, AI-ML/Ops, Python/PyTorch)
Cloud Technology: (e.g., Cloud AI Services, Cloud DevSecOps, Cloud ML Services)
FinOps: (e.g., AI for FinOps, FinOps for Cloud AI, FinOps & TBM)
Agile/PM/Business: (e.g., Scrum Master/PMP, SAFe, Scrum Trainer)
Site Reliability Eng (SRE): (e.g., Incident Mgmt, Monitoring, Infra as Code)
IT Architecture: (e.g., Infrastructure Arch, Enterprise Arch, Cloud Architecture)
Lean Six Sigma/VSM: (e.g., Master Blackbelt, VSM Facilitator, Lean Leader)
Skill Progression
The agent must categorize the employee's current maturity and map future pathways:
Core T Shape: Deep expertise in one vertical pillar
.
Basic N Shape: Deep expertise spanning two vertical pillars
.
Basic M Shape: Deep expertise spanning three vertical pillars
.
4. Required MCP Server Tools
The FastMCP server must expose the following capabilities to the Agentic RAG workflow:
extract_hr_skills: A tool to query the organizational database (or resume storage) for an employee's existing skill tags.
generate_mock_hr_data: A tool powered by the OpenAI API to dynamically generate synthetic, structured JSON profiles of employees if live HR platforms are disconnected
.
calculate_skill_gap: A tool strictly enforcing the Skill * Value mathematics to prevent LLM hallucination of the rankings.
query_learning_resources: A retriever tool that queries the vector database for relevant training materials based on the employee's specific skill gaps.
5. Application Outputs
The final output generated by the QA/Synthesizer agent must be an AI-generated skill plan
. This plan must include:
Action Plans: Concrete steps (e.g., "Complete Data Science Degree", "Get Cloud DevOps Cert (AWS)")
.
Targeted Learning Resources:
Internal: MITRE Internal Ed, Percipio, Skill Soft, Degree Programs
.
External: Udemy, Udacity, Universities, Big Tech, xAcademy, AI-generated classes, and NotebookLM
.
6. Cursor Implementation Guidelines
Iterative Development: Prioritize building the FastMCP tools and data schemas first.
MCP Inspector: Use npx @modelcontextprotocol/inspector to visually verify tool parameter schemas, authentication, and execution before wiring up the LLM agent
.
Agentic RAG Structure: Do not use a traditional single-pass RAG. Implement a multi-agent workflow featuring a Planner, a Retriever, a Tool Agent, and a Verifier to ensure factual consistency and logical skill progression
.
